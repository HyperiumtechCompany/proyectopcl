# Plataforma Web Profesional de Diseño Lumínico

## Visión del Producto

Construir una plataforma web profesional para importar, crear,
administrar y utilizar catálogos de luminarias fotométricas con una
experiencia superior a los flujos tradicionales.

Stack: - React + TypeScript - Laravel - PostgreSQL - Rust - Three.js -
Object Storage

## Arquitectura

React: - Experiencia UX - Visualización - Editor - Interacción

Laravel: - Usuarios - Proyectos - Catálogo - Permisos - API

Rust: - Parser IES - Parser LDT - Parser GLDF - Normalización
fotométrica - Cálculos matemáticos

## Roadmap por Fases

# FASE 0 - Fundación

Objetivo: Crear infraestructura base.

Entregables: - Monorepo - CI/CD - Docker - Autenticación - Diseño UX
base

# FASE 1 - Catálogo Fotométrico MVP

Objetivo: Crear biblioteca profesional.

Funciones: - Fabricantes - Productos - Categorías - Upload IES/LDT -
Buscador - Filtros técnicos

# FASE 2 - Motor de Importación

Objetivo: Crear importador profesional.

Funciones: - Parser IES - Parser LDT - Validación - Importación masiva -
Normalización de datos

# FASE 3 - Catálogo GLDF

Objetivo: Soportar catálogos completos.

Funciones: - Variantes - Imágenes - Modelos 3D - Documentación - Datos
avanzados

# FASE 4 - Visualizador Profesional

Objetivo: Experiencia tipo DIALux web.

Funciones: - Curvas polares - Distribución fotométrica - Vista 3D -
Modelos GLB - Simulación visual

# FASE 5 - Editor de Proyectos

Funciones: - Crear habitaciones - Colocar luminarias - Ajustar
posiciones - Vista 2D/3D

# FASE 6 - Motor Lumínico

Funciones: - Lux - Uniformidad - Emin - Emax - UGR - Curvas isolux

# FASE 7 - Plataforma Empresarial

Funciones: - Portal fabricantes - Equipos - Permisos - API pública -
Estadísticas

## Principios UX

-   El usuario piensa en luminarias, no en archivos.
-   Importación simple mediante arrastrar y soltar.
-   Información progresiva.
-   Flujo rápido para principiantes.
-   Herramientas avanzadas para profesionales.

## Resultado Final

La plataforma será:

Catálogo + Importador + Visualizador + Motor fotométrico + Simulador +
Ecosistema BIM

Un sistema profesional de diseño lumínico web.
